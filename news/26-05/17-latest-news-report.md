## 三、Claude SDK 信用额度调整（补充细节）

> 本节补充 [15 日报告](./15-latest-news-report.md) 第九节的更多细节。

Anthropic 宣布从 **6 月 15 日起**，付费 Claude 计划可为编程式使用申请专属月度信用额度，覆盖：

- Claude Agent SDK
- `claude -p` 命令行
- Claude Code GitHub Actions
- 第三方 Agent SDK 应用

社区核心争议：
- 重度 SDK/CLI 用户的实际价值从"约 $2000 的 token 量"降至约 $200
- 信用额度消耗速度"比订阅使用更快"，严重影响自主 Agent 工作流
- 模糊的产品/使用计费边界使用户难以估算成本
