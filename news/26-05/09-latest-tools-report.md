## 1. Rust 语言新兴项目

### rtk-ai/rtk — LLM Token 消耗优化代理
⭐ 3,340 | 🍴 204 | Rust 单二进制 | CLI 工具

rtk 是一个本地 CLI 代理工具，通过智能压缩和优化 prompt，将 LLM 的 token 消耗降低 **60%-90%**。它以单个 Rust 二进制文件分发，无需运行时依赖。在 AI Agent 日均调用量激增的背景下，token 优化工具对控制 API 成本至关重要。

**来源**: [ossinsight.io/languages/Rust](https://ossinsight.io/languages/Rust)

### TencentCloud/CubeSandbox — AI Agent 安全沙箱
⭐ 627 | 🍴 37 | Rust | 安全基础设施

腾讯云开源的 CubeSandbox 是一个面向 AI Agent 的即时、并发、安全且轻量级的沙箱运行环境。它解决了 AI Agent 执行任意代码时的安全隔离问题，支持高并发场景下的快速启停。继 NVIDIA OpenShell 之后，云厂商也在加速布局 Agent 安全基础设施。

**来源**: [ossinsight.io/languages/Rust](https://ossinsight.io/languages/Rust)

## 趋势总结

1. **Skills 生态爆发**: Skills（技能包）成为 AI Agent 生态的新范式，HelloGitHub 首次将其列为独立分类，Shell 语言排行前两名均为 Skills 配置项目
2. **记忆系统成刚需**: claude-mem（6.8w stars）、graphify（3.6w stars）、MemPalace 等项目密集涌现，解决 AI Agent 的"失忆"痛点
3. **安全基础设施跟进**: CubeSandbox（腾讯）、OpenShell（NVIDIA）等大厂入局 Agent 安全沙箱，表明行业对 AI Agent 安全性的重视升温
4. **从工具到平台**: paseo、nezha 等项目将 AI Agent 从命令行工具升级为跨设备统一管理平台
5. **方法论工程化**: superpowers、andrej-karpathy-skills 等将最佳实践沉淀为可复用的规范，AI 编程从"靠运气"走向"有章法"
