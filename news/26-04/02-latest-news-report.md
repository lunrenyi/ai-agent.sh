## 1. 具身智能全面爆发

### 高德发布全球首个面向 AGI 的全栈具身技术体系"ABot"
高德（阿里巴巴旗下）发布面向 AGI 的全栈具身技术体系 **ABot**，在 15 项全球权威基准测试中达到 SOTA 水平。ABot 采用**三层闭环飞轮**设计：
- **数据层**：ABot-World 可交互世界模型（含 ABot-3DGS 数字孪生工厂 + ABot-PhysWorld 物理思维引擎）
- **模型层**：导航基座 ABot-N + 操作基座 ABot-M
- **Agent 层**：ABot-Claw 机器人操作系统

核心创新在于从"视觉渲染范式"转向"**可微分物理引擎范式**"——ABot-PhysWorld 基于 14B 参数 DiT 架构，引入 Diffusion-DPO 物理偏好对齐框架，解决了物体穿透、无接触抓取等违反物理规律的错误。高德宣布将 ABot-World 开源。

## 2. AI Agent 与开发工具

### 深入拆解 8 种多智能体协作模式
宝玉系统梳理了基于大语言模型的多智能体系统中的 **8 种核心协作模式**：反思模式（Reflection）、顺序模式（Sequential）、层级模式（Hierarchical）、交接模式（Handoff）、混合智能体模式（MoA）、辩论模式（Debate）、嵌套模式（Nested）和自定义模式（Custom）。每种模式各有适用场景——反思模式适合自我改进任务，层级模式适合中心调度工作流，MoA 通过聚合多模型输出提升质量。文章帮助开发者根据实际需求挑选最合适的框架，并在遇到瓶颈时平滑升级。

**来源**: [宝玉的分享](https://baoyu.io/) | 发布于 2026-04-12

### 编程智能体的六大核心组件
源自机器学习专家 Sebastian Raschka 的分析，深入拆解编程智能体的六大核心组件：**代码仓库上下文、提示词缓存、工具调用、上下文瘦身、结构化记忆和子智能体委派**。文章揭示了一个关键洞察——Claude Code 和 Codex CLI 的强大性能并非单纯依赖底层模型，而是源于精心设计的 Agent 架构。这六大组件协同工作，使编程 Agent 能够理解整个项目代码结构、高效复用计算结果、调用外部工具完成复杂任务，并在长会话中保持对关键信息的记忆。

**来源**: [宝玉的分享](https://baoyu.io/) | 发布于 2026-04-05

### 提示缓存机制与 Claude Code 的真实成本
理解提示缓存机制，才能真正搞清楚 Claude Code 的成本结构。Claude Code 的整个底层架构都是围绕 Prompt 缓存设计的，核心原理是"**前缀匹配**"——将静态内容（系统提示词、CLAUDE.md）放在前面，动态内容（用户消息、工具输出）放在后面，实现最大化缓存命中。社区实测缓存命中率可达 **92%**，首 token 延迟降低 **79%**，成本降低最高 **90%**。一个反直觉的结论：很多时候，**继续聊比开新会话更省钱**。

**来源**: [宝玉的分享](https://baoyu.io/) | 发布于 2026-04-06

### Codex 产品负责人详解 10 个要点
OpenAI Codex 产品负责人 Alexander Embiricos 详解产品设计理念：不做中期路线图、50 人团队仅 1 个 PM。这反映了 AI 产品管理的独特哲学——快速迭代比长期规划更重要。

**来源**: [宝玉的分享](https://baoyu.io/) | 发布于 2026-04-06

## 3. GUI 智能体

### 教龙虾玩手机！打通 GUI 智能体全流程
浙江大学 ZJU-REAL 团队推出开源框架 **ClawGUI**，首次打通 GUI 智能体在线 RL 训练（ClawGUI-RL）、标准化评测（ClawGUI-Eval）、真机部署（OpenClaw-GUI）完整生命周期。仅 **2B 参数**的 ClawGUI-2B 模型在 MobileWorld 基准上取得 17.1 SR（成功率），大幅超越基线 11.1，达到接近 8B 模型的水平。创新性地引入 PRM（过程奖励模型）逐步奖励机制，解决了 GUI 长序列决策中奖励稀疏的问题。OpenClaw-GUI 支持通过飞书、QQ、Telegram 等 **12+ 聊天平台**用自然语言控制 Android、鸿蒙、iOS 真机。项目已在 GitHub 开源。

**来源**: [量子位](https://www.qbitai.com/2026/04/403214.html) | 发布于 2026-04-19
