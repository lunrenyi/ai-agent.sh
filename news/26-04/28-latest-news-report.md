**来源**: [量子位](https://www.qbitai.com/) | 发布于 2026-04-27

### Claude 终于认了！降智坐实，越聊越傻，3 个 Bug 全曝光
Anthropic 正式承认 Claude 存在"降智"问题，曝光 3 个核心 Bug：

1. **推理等级偷偷降级**（3 月 4 日）：将默认推理强度从"high"调整为"medium"，但界面仍显示"high"，用户实际拿到的是降档货
2. **缓存 Bug**（3 月 26 日）：缓存优化代码有 Bug，导致每轮对话都清空思考记录，思考中位数从 2200 字符暴跌至 600 字符，下降 **67%-73%**
3. **提示词限制**（4 月 16 日）：系统提示中添加"工具调用之间文字不超过 25 个词"，导致 Opus 4.6 和 4.7 性能下降 **3%**

BridgeBench 测试显示 Opus 4.6 准确率从 83.3% 跌至 68.3%，排名从第 2 跌到第 10。许多用户已转向 Codex、MiniMax 等替代品。业界出现"AI shrinkflation"（AI 缩水通胀）概念，指同样价格得到稀释的产品。4 月 19 日 Anthropic 发布 Claude Opus 4.7 试图修复。

**来源**: [量子位](https://www.qbitai.com/) / [凤凰网](https://h5.ifeng.com/c/vivoArticle/v002-_53qgeCnVgPJV3ZaIO2oratUCZScWuMIWZjCLtneHOE__) | 发布于 2026-04-27

## 2. AI Agent 与开发工具

### 深入拆解 5 种多智能体协作模式的运作原理与优缺点
宝玉系统梳理了基于大语言模型的多智能体系统中的核心协作模式。文章从反思模式（Reflection）、顺序模式（Sequential）、层级模式（Hierarchical）、交接模式（Handoff）、混合智能体模式（MoA）等维度展开，帮助开发者根据实际需求选择最合适的框架。

**来源**: [宝玉的分享](https://baoyu.io/) | 发布于 2026-04-12

### 理解提示缓存机制，搞清楚 Claude Code 成本结构
深入分析 Claude Code 的 Prompt 缓存设计原理——"前缀匹配"。将静态内容（系统提示词、CLAUDE.md）放前面，动态内容放后面，实现最大化缓存命中。社区实测缓存命中率 **92%**，首 token 延迟降低 **79%**，成本降低最高 **90%**。反直觉结论：**继续聊比开新会话更省钱**。

**来源**: [宝玉的分享](https://baoyu.io/) | 发布于 2026-04-06

### Codex 产品负责人详解 10 个要点
OpenAI Codex 产品负责人 Alexander Embiricos 详解产品设计理念：不做中期路线图、50 人团队仅 1 个 PM，体现了 AI 产品管理中快速迭代优于长期规划的哲学。

**来源**: [宝玉的分享](https://baoyu.io/) | 发布于 2026-04-06

### 深入拆解编程智能体的六大核心组件
基于 Sebastian Raschka 的分析，揭示编程智能体核心组件：代码仓库上下文、提示词缓存、工具调用、上下文瘦身、结构化记忆和子智能体委派。关键洞察：Claude Code 和 Codex CLI 的强大性能不仅依赖底层模型，更源于精心设计的 Agent 架构。

**来源**: [宝玉的分享](https://baoyu.io/) | 发布于 2026-04-05

### Claude Code 源码泄漏后的正确学习方式
四步递进学习法：**跑起来 → 从功能点切入 → 二次开发 → 从零搭建**，比单纯阅读源码分析文章更有价值。

## 本期趋势观察

**价格战白热化，DeepSeek 领跑。** DeepSeek V4 永久降价并将缓存价格打到 1 折，直接导致 OpenClaw 等项目从 Claude 迁移到 DeepSeek。结合同期 Claude 降智 Bug 被曝光、Anthropic 被迫承认，大模型市场的竞争已经从"谁的模型更强"转变为"谁的性价比更高"。

**Claude 的信任危机。** Anthropic 在 3 月偷偷降低推理强度、缓存 Bug 导致思考记录丢失、编辑效率退化等一系列问题被集中曝光，思考能力下降 67%-73%。虽然 4 月 19 日发布了 Opus 4.7 试图修复，但对开发者社区的信任影响深远。

**AI Agent 工程化知识加速沉淀。** 宝玉连续发布的系列文章（提示缓存、编程 Agent 组件、多智能体协作模式）表明，AI Agent 领域正在从"模型能力竞争"转向"工程化能力竞争"。谁能在缓存策略、上下文管理、多智能体协调上做得更好，谁就能在实际应用中胜出。

**自动驾驶进入 AI 智能体时代。** 华为 ADS 5 明确提出从"辅助驾驶工具"升级为"AI 智能体"，引入多智能体博弈机制。这标志着自动驾驶技术路线正式从规则驱动转向智能体驱动。
