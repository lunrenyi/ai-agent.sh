# Anthropic 蜂巢思维：软件开发的未来

> 作者：Steve Yegge
> 原文发布于：2026年2月6日
> 原文：The Anthropic Hive Mind

## 核心观点

Steve Yegge 在这篇文章中提出了一个大胆的预测：**软件开发的未来是"蜂巢思维"（Hive Mind）模式**。他在过去四个月与 Anthropic 约40人的深入交流中，观察到这家公司正在以一种前所未有的方式运营，预示着整个行业即将发生的变革。

---

## 1. Anthropic 的独特氛围

### 人才密度
- 进入 Anthropic 的难度可与进入 NFL 相提并论
- 这里的每个人都比 Google 全盛时期还要"最好中的最好"
- （证据：Google 雇了 Steve，他是自己那批人中最差的）

### 整体感受
- 每个人都充满活力，但又带有一种"甜蜜而悲伤的超越感"
- 像一群被赋予使命的人：将某种文明级别重要性的东西带入现实
- 他们对很多公司的态度是"真诚的同情"，因为**2026年将会是让很多公司崩溃的一年**

---

## 2. 蜂巢思维运作模式

### "氛围驱动"的公司
Anthropic 与同规模公司完全不同：
- 没有其他公司的"职业化"、条块分割、责任明确
- 核心运作完全依靠"氛围"（vibes）
- 员工自己也承认公司是"完全靠氛围运行的蜂巢思维"

### 运作特点
- **无限的工作，没有竞争**：公司正处于黄金时代，可用的工作远多于人数
- **每个人都能把想法"放到阳光下"**，由蜂巢思维评判其价值
- 如果你干扰蜂巢思维的运作，会被轻轻推到边缘
- 整个团队像"即兴表演"："Yes, and..." 风格，每个想法都被欢迎、审视、品味

### 黄金时代的开始与终结
Steve 分享了他观察到的"黄金时代"规律：

| 公司 | 黄金时代 | 终结原因 |
|------|----------|----------|
| Google | 到2011年4月 | 专注利润，工作/人员比例下降，开始政治斗争 |
| Amazon | 持续较长时间 | 保持"永远略微超负荷"的状态 |
| Microsoft | 2000年代初 | .NET 黄金期后人才流失到 Google |

**核心洞察**：黄金时代开始于**工作多于人**，终结于**人多于工作**。

## 3. 小型蜂巢思维案例：SageOx

Steve 介绍了他的朋友 Ajit、Ryan 和 Milkana 创办的 3 人创业公司 SageOx：

### 运作方式
- 住在 Kirkland 的小公寓里，楼上咖啡店
- 几个月不穿鞋子走下去买咖啡
- **完全透明**：每个人随时公开自己在做什么
  - "我要下去买甜甜圈！"
  - "帮我带一个！"
  - "我正在删除数据库！"
  - "好的。"

### 透明度带来的好处
- 所有工作完全公开，像整个团队同时进行结对编程
- 实时互相纠正
- 记录所有对话，自动上传和版本化
- 保留每个人类和智能体的完整工作历史

### 开发者的不适
- 大多数开发者会感到非常不舒服
- **因为这是"自我"的死亡**：每个人都能看到你所有的错误和绕弯
- 你无法隐藏任何东西，必须成为一只"快乐的蜜蜂"

## 4. 篝火模型

### 对比传统模式
Steve 在 Thoughtworks 组织的活动中提出了这个比喻：

| 传统模式 | 篝火模型 |
|----------|----------|
| 部门 silos（筒仓） | 围坐在篝火旁 |
| 瀑布式开发 | 没有规范，没有规范 |
| 复杂的规格文档 | 只有一个不断进化的原型 |

### 篝火模型特点
- 篝火中心是一个**活原型**
- 通过"集体雕塑"逐渐演化为最终产品
- 找到"感觉对了"的那一刻，你就知道了
- Anthropic 的最长规划周期不超过 **90 天**

### 即兴表演的规模化
- Anthropic 工程师像在用黏土一起雕塑
- 围绕各种"火焰"（进行中的产品）形成蜂群
- 人们尝试新变体和混搭时，产品形状会改变
- **当魔法发生时，它会非常快**：据报道，Claude Cowork 从有想法到公开发布只用了 10 天

## 5. 对其他公司的警告

### 公司们的两个核心问题
Sales 部门的人告诉 Steve，所有公司都在问两个问题的变体：
1. "一切都会好吗？"
2. "我们五年后还会在这里吗？"

### 答案
- **默认答案是"不"**
- 如果你什么都不做，几乎肯定会被淘汰
- 如果你有"原子护城河"（原子级实体产品），就有更好的机会生存
- 如果你只有纯电子化的 SaaS 产品，**坦白说，你完了，除非转型**

### 转型之路
- **花 tokens**：这条"黄金之路"会带领你的公司逐步走向正确的方向
- 编码不再是瓶颈后，需要学习新的组织层面的教训
- 判断学习程度的指标：**token 消耗量**

## 6. 给读者的建议

Steve 的核心建议：

1. **学习 AI**：现在开始，不要等待
2. **建立篝火**：让产品成为活原型
3. **在公司内建立蜂巢**：给团队创新的空间
4. **全力转型**：找到你的新 PMF（产品-市场契合点）

> "祝你好运。这将是疯狂的一年。愿最好的……whatever……获胜。"

## 总结

这篇文章的核心洞见是：

| 概念 | 要点 |
|------|------|
| **蜂巢思维** | 全透明、无限工作、"自我死亡"的工作文化 |
| **黄金时代** | 工作多于人 = 创新；人多于工作 = 政治斗争 |
| **篝火模型** | 无瀑布、活原型、90天最短规划周期 |
| **即兴表演** | "Yes, and..." 风格，欢迎每个想法 |
| **生存策略** | 学习 AI、建立原子护城河、持续 token 实践 |

Steve 认为，Anthropic 正在展示未来所有成功公司都将采用的运作方式，尽管它与今天大多数公司的运作方式截然不同。
