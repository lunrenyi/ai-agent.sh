# AI 图像生成 Prompt 设计分析：结构化「规格说明书」范式

> 本文分析一个用于生成幻灯片演示的 AI 图像生成 Prompt，拆解其通用结构、设计理念与工程实践。

---

## 一、Prompt 概述

这份 Prompt 来自 baoyu，旨在生成一组**三页演示幻灯片**。整个 Prompt 呈现出高度结构化的特征，宛如一份「视觉设计规格说明书」。

### 目标产物
- 3 页幻灯片（16:9 宽屏）
- 主题：技术产品的功能演示
- 风格：温暖手绘插画风（速写本质感）

---

## 二、Prompt 结构拆解

### 2.1 顶层指令层（CORE DIRECTIVES）

Prompt 开篇定义了 5 条核心指令，类似于「宪法」层面的约束：

```
1. 分析用户提示词的结构、意图和关键要素
2. 将指令转化为干净、结构化的视觉隐喻
3. 使用特定的、克制的调色板和字体系列
4. 所有视觉输出必须严格保持 16:9 的长宽比
5. 以三联画或基于网格的布局呈现信息
```

**设计意图**：这 5 条指令确保 AI 在生成图像时不会「放飞自我」，而是严格遵循预设的美学规范和输出格式。

### 2.2 风格指令层（STYLE INSTRUCTIONS）

第二层定义了完整的视觉规范，包含 6 个维度：

| 维度 | 规范 |
|------|------|
| 设计美学 | 温暖手绘插画，模拟艺术家速写本，线条带自然波浪感 |
| 背景颜色 | #F9F7F2 柔和米白色，水彩纸纹理 |
| 主要字体 | 演示悠然小楷/手写圆体风格 |
| 辅助字体 | 清晰手写体/圆润无衬线体 |
| 主色调 | #3E3C38 暖炭灰（模拟铅笔/墨水） |
| 强调色 | #FF7F7F 珊瑚红 + #8FA87A 鼠尾草绿 |

**关键洞察**：这种「枚举式」的风格定义避免了 AI 的「二创」冲动，让输出高度可预测。

### 2.3 内容层（CONTENT TO DRAW）

第三层是真正的「Payload」，每个幻灯片都采用四段式结构：

```markdown
## Slide N: 标题

// NARRATIVE GOAL
叙事目标：让观众意识到...

// KEY CONTENT
关键内容：标题、副标题、核心痛点...

// VISUAL
视觉描述：画面中心是...，背景是...

// LAYOUT
布局说明：中心构图，大字号标题...
```

这种「Goal → Content → Visual → Layout」的闭环设计，确保每一页的叙事逻辑与视觉呈现保持一致。

## 三、每页幻灯片的通用结构

### Slide 1：封面（痛点大字报）

- **叙事目标**：警示 + 共鸣
- **核心内容**：大标题 + 副标题 + 署名
- **视觉设计**：中心构图，视觉冲击优先
- **布局策略**：痛点以图标+卡片形式散开

### Slide 2：解决方案演示

- **叙事目标**：展示实际用法，建立操作认知
- **核心内容**：命令/代码示例 + 概念解释
- **视觉设计**：左侧示例区 + 右侧概念卡
- **布局策略**：60/40 分栏，对比展示

### Slide 3：价值总结

- **叙事目标**：简化理解，促进行动
- **核心内容**：核心命令重复 + 价值点列表
- **视觉设计**：命令 + 价值卡片 + 手绘图标
- **布局策略**：左右分栏 + 底部 Slogan 收尾

## 四、Prompt 工程的「规格说明书」范式

这份 Prompt 展现了一种高效的 AI 图像生成范式，我称之为**「规格说明书」模式**：

### 4.1 分层控制

```
顶层：目标约束（做什么）
    ↓
中层：风格约束（怎么做）
    ↓
底层：内容约束（具体做啥）
```

### 4.2 确定性优先

- 明确指定色值（Hex Code）
- 明确指定字体系列
- 明确指定长宽比
- 明确指定布局比例

这与「模糊创意提示」形成鲜明对比——规格说明书追求的是**可复现性**，而非「惊喜感」。

### 4.3 叙事逻辑贯穿

每一页都遵循 `NARRATIVE GOAL → KEY CONTENT → VISUAL → LAYOUT` 的链条，确保：
1. **为什么要画这个**（Goal）
2. **画什么内容**（Content）
3. **怎么画**（Visual）
4. **画在哪里**（Layout）

---

## 五、关键设计决策

### 5.1 为什么用手绘风格？

手绘风格传递「亲和力」与「可信度」——它暗示这不是一台冷冰冰的机器在执行命令，而是一个真实的分享者在传递信息。

### 5.2 为什么用 16:9？

标准的演示比例，确保输出可直接用于投屏或视频制作。

### 5.3 为什么重复核心内容？

在 Slide 2 和 Slide 3 中重复核心命令/内容，是一种**记忆强化**策略——让观众至少记住一个关键信息。

---

## 六、总结

这份 Prompt 的核心价值在于**将「创意」转化为「规格」**：

1. **结构化**：CORE → STYLE → CONTENT 三层递进
2. **确定性**：所有视觉参数均可度量
3. **叙事驱动**：每页都有明确的传播目标
4. **工程化**：输出可直接用于生产

这种「规格说明书」范式特别适合：
- 企业级演示素材生成
- 产品功能图解
- 教程插图批量生产

**一句话总结**：与其让 AI 自由发挥，不如给它一份详细的「施工图纸」——这份 Prompt 正是那份图纸。
