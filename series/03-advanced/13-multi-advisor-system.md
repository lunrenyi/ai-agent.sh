# 六位思想巨人装进我的系统：CC 多顾问架构实践

> 把德鲁克、乔布斯、原研哉、芒格、巴菲特、马斯克装进 Claude Code，每次决策先问他们。

## 核心概念

把 6 位最尊敬的人装进工作系统，各司其职。每次在对应领域要做决策时，先问问他们——这不是玄学，是一套实际在跑的 **CC 架构（Claude Code 多顾问系统）**。

## 六大顾问

### 01 商务增长顾问：彼得·德鲁克（Peter Drucker）

**核心问题**：你的客户是谁？你在为他们创造什么价值？

每次想推新功能、写新文章，先让这个 Agent 问这两个问题。90% 的"好想法"在这里就死掉了——死得其所。

帮他砍掉了 3 个看起来很好、实际没有用户需求的功能。

### 02 产品设计顾问：史蒂夫·乔布斯（Steve Jobs）

**核心问题**：这是最好的体验吗？还是只是能用？

不在乎做了多少，只问体验是否极致。他会说："这里多余，删掉。这里体验断了，重做。"

用了他之后，产品页面砍掉了一半内容，但转化率反而上去了。

### 03 系统架构顾问：原研哉（Kenya Hara）

**核心问题**：这个东西，有没有必要存在？

少即是多，不是口号，是设计哲学。当工作区乱得像垃圾场——文件夹套文件夹、流程套流程，让原研哉扫一遍。

删掉 60% 之后，剩下的 40% 运转得更顺了。

### 04 投资顾问：查理·芒格（Charlie Munger）

**核心方法**：多元思维模型

用物理学思考时间，用心理学思考人性，用经济学思考激励。

每次要做重大决策——要不要招人、要不要做某个市场、要不要签某个合作——让芒格用至少 3 个不同的学科框架来拆解。

他帮我识别了两次"感觉很好但实际是陷阱"的机会。

### 05 商业顾问：沃伦·巴菲特（Warren Buffett）

**核心原则**：护城河——你有什么别人抄不走的东西？

只做一件事：帮我拒绝。

每次焦虑"要不要跟上某个新趋势"，让巴菲特来回答，他通常会说："专注你能做到最好的那件事，其他的无视。"

这是做留学业务能坚持"高端窄众"而不是"什么都做"的底层逻辑。

### 06 执行速度顾问：埃隆·马斯克（Elon Musk）

**核心问题**：你为什么还没开始？

前 5 位帮你想清楚——马斯克帮你动起来。

当觉得"再准备准备"、"再等等时机"、"再完善一下"，马斯克会说："你在等什么？完美是执行的敌人，先发出去，迭代比计划更有力量。"

他还会用第一性原理拆解每个"做不到"："这是真正的限制，还是你自己设的边界？"

被他问过之后，至少有 3 件事从"打算做"变成了"已经发布"。

## 为什么这么做？

一个人的认知是有限的。但这 6 个人，每一个都花了几十年磨出了一套世界级的思维体系。

与其从零摸索，不如让他们的思维成为系统的一部分——每次要做决策，自动激活对应的顾问框架。

这不是在抄他们，这是在站在巨人的肩膀上做决策。

## 如何现在就开始用？

选一个你最尊敬的人，花 30 分钟，把他最核心的 3 个原则写下来，装进你的系统提示词里。然后在下次做决策前，先让他过一遍。

你会发现，你的决策质量会静悄悄地提升一个档次。

## 技术实现

这套多顾问体系需要用到 Claude Code 里的 **Agent Team 功能**，再结合自己定制的 **Skill** 一起运行。

不是装一下提示词就能跑的东西——它是一个需要长期磨合、持续迭代的过程。
