# Simon Willison：启动 Agentic Engineering Patterns 项目

> 2026年2月23日 — Simon Willison Blog

## 项目启动

2026年2月23日，知名 宣布启动一个新开发者 Simon Willison项目：**Agentic Engineering Patterns**（智能体工程模式）。这是一个系统性地收集和记录编码智能体工程实践的项目，旨在整理帮助开发者更好地使用编码智能体的编码实践和模式。

## 核心定义

> **Agentic Engineering**：使用编码智能体（如 Claude Code、OpenAI Codex）构建软件，其核心特征是能够**生成和执行代码**。

## 与 Vibe Coding 的区别

| 概念 | 定义 | 适用人群 |
|------|------|----------|
| **Vibe Coding** | 使用 LLM 写代码，但不关注代码本身 | 非程序员 |
| **Agentic Engineering** | 专业软件工程师利用编码智能体提升工作效率 | 专业工程师 |

Simon 强调：Vibe Coding 是让非程序员也能构建软件的方式，而 Agentic Engineering 则是专业工程师利用智能体作为工具来加速和提升工作。

## 已发布内容

项目采用 **"Guides"（指南）** 的形式，每个章节设计为可长期更新的常青内容，而非固定在发布时的状态。

### 第一章：Writing code is cheap now

讨论了生成初始代码的成本已降至几乎为零，以及这一变化如何影响现有工作方式。

### 第二章：Red/green TDD

描述测试驱动开发（TDD）如何帮助编码智能体编写更简洁、更可靠的代码。

## 核心观点

1. **编码成本大幅下降**：生成初始代码的成本已接近于零
2. **TDD 助力智能体开发**：测试驱动开发能帮助智能体写出更好的代码
3. **常青内容形式**：采用 Guides 和 Chapters 的形式，内容可持续更新

## 写作原则

Simon 表示他不会以自己的名义发布 AI 生成的写作，但会使用 LLMs 进行：
- 校对
- 完善示例代码
