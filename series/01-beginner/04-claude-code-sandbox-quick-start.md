# 5 分钟上手 Claude Code 沙箱隔离

> 这可能是你最重要的安全设置

## TL;DR

沙箱隔离 = 给 Claude Code 加上"安全气囊"。开启后，它只能在限定范围内工作，即使被黑客控制也无法访问你的敏感文件。

## 一句话解释

想象你家请了个保姆，沙箱隔离就像是给保姆一间独立的工作室：
- 她可以自由使用工作室里的东西
- 但不能随意进入你的卧室、书房
- 也无法偷偷向外打电话

这就是 Claude Code 沙箱隔离做的事。

## 为什么要开？

### 不用沙箱的风险

```
你的电脑 ←→ Claude Code ←→ 外部攻击者
                            ↑
                     如果 Claude 被"洗脑"了呢？
```

虽然这种情况极少，但不怕一万就怕万一。沙箱隔离确保：

| 没有沙箱 | 有沙箱 |
|---------|--------|
| Claude 可以访问你电脑上的任何文件 | 只能访问你指定的项目目录 |
| 可以向任何网站发送数据 | 只能访问你允许的域名 |
| 如果被攻破，你的 SSH 密钥可能泄露 | 攻击者无法触及敏感区域 |

### 开启后的好处

1. **减少批准弹窗**：沙箱内的操作自动放行，不用每次都点"批准"
2. **更安全的自主运行**：Claude 可以在限定范围内自己干活
3. **安心**：即使出问题，损失也控制在最小范围

## 怎么开启？

### 第一步：运行命令

在 Claude Code 中输入：

```text
/sandbox
```

会弹出一个菜单让你选择模式。

### 第二步：选择模式

| 模式 | 适合人群 | 体验 |
|------|---------|------|
| **自动允许** | 大多数用户 | 推荐！沙箱内的命令自动运行，偶尔才需要你确认 |
| **常规权限** | 安全要求极高 | 每条命令都要确认，比较繁琐 |

**建议选「自动允许」**，这是官方推荐的用法。

### 第三步（可选）：配置可访问的目录

如果你的项目不在当前目录，或者需要访问其他文件夹，编辑 `settings.json`：

```json
{
  "sandbox": {
    "enabled": true,
    "filesystem": {
      "allowWrite": ["~/my-projects", "//tmp/build"]
    }
  }
}
```

简单理解：
- `~/` 开头 = 你家目录下的文件夹
- `//` 开头 = 电脑上的绝对路径

## 开启后会有什么变化？

### 你会注意到的变化

✅ **更少的弹窗**：之前每次执行命令都要确认，现在沙箱内的操作自动通过

⚠️ **偶尔会弹窗**：当 Claude 尝试访问沙箱外的资源时，会提醒你

❌ **某些命令可能失败**：比如需要访问特定网站的工具

### 遇到命令失败怎么办？

如果 Claude 报错说"无法访问某文件/网站"，它会：
1. 分析失败原因
2. 问你是否要：
   - 允许这次访问
   - 永久添加到白名单
   - 在沙箱外重试（需要额外授权）

## 常见问题

### Q: 开启沙箱会影响正常工作吗？

大部分情况下不会。如果你发现某个常用命令失败了，Claude 会主动提示你添加白名单。

### Q: 我还能手动批准命令吗？

可以。在沙箱设置中，你可以定义"每次都要问"的规则。

### Q: 沙箱真的安全吗？

沙箱隔离是操作系统级别的保护（macOS 用 Seatbelt，Linux 用 bubblewrap），不是简单的规则列表。这意味着即使用的是第三方工具（如 kubectl、npm），也会被沙箱限制。

### Q: 可以只开文件隔离，不开网络隔离吗？

不可以。官方明确说明：必须同时开启，否则等于没开。

## 什么时候该关闭沙箱？

- 调试特定问题（临时）
- 使用某些不兼容的工具（临时）
- 官方明确支持后
