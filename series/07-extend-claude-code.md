# Claude Code 扩展指南

> [扩展层功能完全指南](https://code.claude.com/docs/en/features-overview#subagent-vs-agent-team)

---

## 概述

Claude Code 将推理模型与内置工具（文件操作、搜索、执行、Web 访问）相结合，内置工具覆盖大部分编码任务。本指南介绍扩展层：定制 Claude 的认知、连接外部服务、自动化工作流。

核心扩展点：
- **CLAUDE.md** - 持久上下文
- **Skills** - 可复用知识和工作流
- **MCP** - 外部服务连接
- **Subagents** - 隔离上下文执行
- **Agent teams** - 多会话协调
- **Hooks** - 确定性脚本事件
- **Plugins** - 打包分发

---

## 功能匹配

| 功能 | 作用 | 适用场景 | 示例 |
|------|------|----------|------|
| **CLAUDE.md** | 每次会话加载持久上下文 | 项目规范、"始终做 X"规则 | "使用 pnpm而非 npm，提交前运行测试" |
| **Skill** | 可复用的指令、知识、工作流 | 参考文档、可触发工作流 | `/review` 运行代码审查清单 |
| **Subagent** | 隔离上下文，返回摘要结果 | 上下文隔离、并行任务 | 研究任务读取多文件但只返回关键发现 |
| **Agent teams** | 协调多个独立会话 | 并行研究、新功能开发、多假设调试 | 生成安全、性能、测试审查员同时工作 |
| **MCP** | 连接外部服务 | 外部数据或操作 | 查询数据库、发送 Slack、控制浏览器 |
| **Hook** | 确定性脚本事件触发 | 可预测自动化 | 每次文件编辑后运行 ESLint |

## 相似功能对比

### Skill vs Subagent

| 维度 | Skill | Subagent |
|------|-------|----------|
| **本质** | 可复用指令、知识、工作流 | 隔离上下文的独立工作者 |
| **关键优势** | 跨上下文共享内容 | 上下文隔离，工作单独进行只返回摘要 |
| **最佳场景** | 参考材料、可触发工作流 | 读取大量文件、并行工作、专职工作者 |

**组合使用**：Subagent 可以预加载特定 Skill；Skill 可以使用 `context: fork` 在隔离上下文运行。

### CLAUDE.md vs Skill

| 维度 | CLAUDE.md | Skill |
|------|-----------|-------|
| **加载时机** | 每次会话自动加载 | 按需加载 |
| **可包含文件** | 支持 @path 导入 | 支持 @path 导入 |
| **可触发工作流** | 不支持 | 支持 /<name> 触发 |
| **最佳场景** | "始终做 X"规则 | 参考材料、可触发工作流 |

**经验法则**：CLAUDE.md 保持 500 行以内，增长时将参考内容移至 Skill。

### Subagent vs Agent Team

| 维度 | Subagent | Agent Team |
|------|----------|------------|
| **上下文** | 独立窗口，结果返回主智能体 | 独立窗口，完全自主 |
| **通信** | 仅向主智能体汇报 | 队友之间直接通信 |
| **协调** | 主智能体统一管理 | 共享任务列表，自主协调 |
| **最佳场景** | 只需结果的专注任务 | 需要讨论协作的复杂工作 |
| **Token 成本** | 较低：摘要返回主上下文 | 较高：每个队友是独立实例 |

**转换点**：如果并行 Subagent 达到上下文限制，或需要互相通信，Agent Teams 是自然升级。

### MCP vs Skill

| 维度 | MCP | Skill |
|------|-----|-------|
| **本质** | 连接外部服务的协议 | 知识、工作流、参考材料 |
| **提供** | 工具和数据访问 | 知识、工作流、参考材料 |
| **示例** | Slack 集成、数据库查询、浏览器控制 | 代码审查清单、部署工作流、API 风格指南 |

**协同**：MCP 赋予 Claude 与外部系统交互的能力；Skill 教 Claude 如何有效使用这些工具。

## 功能层级

扩展可以在多个层级定义：用户级、项目级、插件级、托管策略。

### 叠加规则

- **CLAUDE.md**：累加性，所有层级内容同时加载，更具体的指令通常优先
- **Skill/Subagent**：按名称覆盖，同名时按优先级生效（托管 > 用户 > 项目）
- **MCP**：按名称覆盖，本地 > 项目 > 用户
- **Hooks**：合并，所有注册 Hook 对匹配事件都会触发

---

## 常用组合模式

| 模式 | 工作原理 | 示例 |
|------|----------|------|
| **Skill + MCP** | MCP 提供连接，Skill 教如何用好它 | MCP 连接数据库，Skill 记录数据模型和查询模式 |
| **Skill + Subagent** | Skill 生成 Subagent 并行工作 | `/review` 启动安全、性能、风格 Subagent 隔离工作 |
| **CLAUDE.md + Skills** | CLAUDE.md 保持规则，Skills 按需加载 | CLAUDE.md 说"遵循 API 规范"，Skill 包含完整 API 风格指南 |
| **Hook + MCP** | Hook 通过 MCP 触发外部操作 | 编辑关键文件后 Hook 发送 Slack 通知 |

## 上下文成本

每个功能消耗上下文的方式不同：

| 功能 | 加载时机 | 加载内容 | 上下文成本 |
|------|----------|----------|------------|
| **CLAUDE.md** | 会话开始 | 完整内容 | 每次请求 |
| **Skills** | 开始 + 使用时 | 描述开始使用，完整内容调用时 | 低（描述每次请求）* |
| **MCP** | 会话开始 | 所有工具定义和 JSON Schema | 每次请求 |
| **Subagents** | 生成时 | 指定 Skill 的全新上下文 | 与主会话隔离 |
| **Hooks** | 触发时 | 无（外部运行） | 零，除非 Hook 返回内容 |

\* 默认 Skill 描述在会话开始加载，Claude 可决定何时使用。设置 `disable-model-invocation: true` 可完全隐藏，直到手动调用。

### 加载时机

- **CLAUDE.md**：会话开始加载，保留在每次请求中
- **Skills**：默认描述开始加载，完整内容按需加载
- **MCP**：会话开始加载所有工具定义
- **Subagents**：按需生成隔离上下文
- **Hooks**：触发时外部运行

---

## 总结

扩展层各司其职：
- CLAUDE.md → 持久上下文
- Skills → 按需知识和工作流
- MCP → 外部连接
- Subagents → 隔离执行
- Hooks → 自动化

**最佳实践**：保持 CLAUDE.md 简洁（<500 行），将参考内容移至 Skills，需要隔离或并行时用 Subagents，需要协作时用 Agent Teams。
